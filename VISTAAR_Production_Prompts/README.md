# VISTAAR Production Prompts

Use these prompts sequentially in Antigravity. Start with 00 and do not paste all prompts into one task.

- 00–02 Foundation/UI
- 03–06 Real NPDC data/database
- 07–08 Auth/governance
- 09–10 PDF/RAG
- 11–14 AI/verification
- 15–16 Review/weather
- 17–25 Public product/education/media/search/admin
- 26–32 Security/performance/operations/testing/deployment/exports
- 33–37 Final audits/readiness

Hard UI requirement: warm beige/ivory background #FAF7F0, white surfaces #FFFFFF, charcoal text #17202A, warm borders #E7E0D5, scientific blue #2563EB, cyan #0E7490. No dark dashboard, black cards, neon, excessive gradients, or glassmorphism.

Production rule: real NPDC/NCPOR data only in production; raw source files immutable; no fake scientific measurements; AI never publishes without authorized human approval; every scientific claim must retain provenance.
